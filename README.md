# Josie's Portofolio

Interactive 3D portfolio for **Josyca Nauli**, a graphic designer and Digital Journalism student at Universitas Multimedia Nusantara. All content and visual direction come from the Canva deck `UPDATED PORTOFOLIO_JOSYCA N..pdf`.

**Stack:** Vite · React · TypeScript · Three.js (React Three Fiber + drei) · GSAP + ScrollTrigger · Lenis · Framer Motion · Tailwind CSS v4

## Running locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check + production build into dist/
npm run preview    # serve dist/ at http://localhost:4173/josie-portofolio/
```

## Structure

```
src/
  data/         all content from the deck (about, organizations, projects, contact, credits, image sizes)
  sections/     Hero, About, Toolkit, Organizations, CaseStudies, Projects, Contact
  components/   Nav, Logo, Loader, Cursor, Magnetic button, Polaroid, Lightbox, Media, Bits
  three/        3D scene: Reel, FilmRibbon (shader), Statement cylinder, ToolTiles, Dust, rig poses
  animations/   easing tokens, GSAP setup, Lenis ↔ ScrollTrigger, reveal hooks, scene scroll binding
  hooks/        media-query hooks (reduced motion, fine pointer)
  styles/       Tailwind theme tokens + base styles
public/assets/  WebP crops of the deck (generated by scripts/extract-assets.mjs)
```

### How the 3D narrative works

One film reel travels through the whole page. Each section has a `data-scene` key. `useSceneScroll` tweens a shared `rig` object from pose to pose (`src/three/rig.ts`) as each section scrolls in, and the scene reads `rig` every frame. The reel tilts toward the pointer, a warm light follows the cursor, and scroll speed spins the reel and ripples the film strip.

### Sound

`src/audio/sound.ts` synthesises every sound with the Web Audio API, so there are no audio files and no licences to track. The sounds are a projector hum with 24 fps clatter, reel ticks while scrolling, hover clicks, a nav tick, a camera shutter when the lightbox opens, and a leader beep. Sound is **off by default** and is switched on with the toggle in the nav (bottom-right on phones). The choice is remembered, but browsers still need one click or key press per visit before audio can play. Under reduced motion the ambient hum and scroll ticks stay off.

### Re-cropping images from the deck

The PDF is flattened: each page is a single bitmap, so assets are cropped from page renders.

```bash
pdfimages -png "UPDATED PORTOFOLIO_JOSYCA N..pdf" .cache/deck/page
npm run assets
```

## Deployment (GitHub Pages)

`.github/workflows/deploy.yml` builds the site and deploys it on every push to `main`.

1. The repository name must match `REPO_NAME` in `vite.config.ts` (currently `josie-portofolio`).
2. On GitHub, go to **Settings → Pages → Source** and select **GitHub Actions**.
3. The live site is https://jonathancahyo.github.io/josie-portofolio/
